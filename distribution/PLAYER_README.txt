THE ALLOTMENT - WINDOWS GARDEN BETA

1. Copy the whole "The Allotment" folder from the USB/CD or extract the ZIP.
2. Double-click "The Allotment Launcher.exe". Keep its PCK and starter files beside it.
3. The launcher installs a local copy under your Windows user account. Click Play garden.

Godot and Python are NOT required to play. No administrator account or online login is required.
Windows 10/11, 64-bit, and a graphics driver supporting Godot Compatibility rendering are needed.
The first install works from the included starter-game.zip even without internet.

The launcher checks for updates when opened and every 30 minutes while idle.
With automatic updates checked, verified new versions install while the game is closed.
Updates do not interrupt an open garden. You can cancel a download and keep playing your current version.
Use previous version switches game files back; it does not roll back garden saves.

Your local garden saves stay in:
%APPDATA%\Godot\app_userdata\The Allotment - Garden World v0.2\
Use Save garden in the game. Settings -> Open my save folder shows your profiles/backups.
Plant growth still uses real elapsed device time, including offline time.
Do not run two copies of the game at once or change profiles from another copy while playing.

The initial beta update channel may not have a published release yet.
If the launcher says the channel is unavailable, the included version still plays offline.
This beta has not been signed with a Microsoft publisher certificate; Windows may show an unknown-publisher warning.

Only give friends the player folder/USB ZIP. The owner's separate publisher kit is not part of the game.
A CD is read-only: updates install on the computer, not on the disc.
