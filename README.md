# The Allotment — updated playable preview

This branch contains the updated Godot project. Download this branch as a ZIP, extract it, then import `the-allotment-garden-world-v-02/project.godot` in Godot Project Manager. Press F5 to start. See the project's START_HERE.md for details.

This is a separate preview branch. The main branch has not been changed.

The download includes the playable project, credits and license evidence. Optional Blender authoring files, raw source meshes and preview screenshots are omitted. To keep delivery files manageable, the gardener model uses standard glTF with two external buffers; this preserves the original geometry, textures, rig and animations without a reconstruction step.
