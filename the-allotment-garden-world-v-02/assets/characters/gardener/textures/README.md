# Gardener surface textures

Original, seamless material maps created for The Allotment. No reference-image pixels or downloaded photographs are used. Rebuild with `python3 ../source/build_surface_textures.py` from this directory (Python 3, NumPy, Pillow, SciPy).

The linen, hair, leather and straw `*_detail.png` textures pack **R: dye-neutral shade variation, G: height, B: roughness**. These are linear data textures: sampler uniforms intentionally omit `source_color`. Each `*_normal.png` is a tangent-space normal map. Maps are 512 × 512; the embroidery masks and normal are 1024 × 1024.

`botanical_embroidery.png` packs rose-petal thread in R, stems/leaves in G, and old-gold flower centers/running stitches in B. `fabric.gdshader` recolors these masks using the player's clothing and flower colors. The relief comes from `embroidery_normal.png`, preserving a raised-thread appearance after recoloring.

All shaders share mipmapped repeat sampling and reduce fine normal detail with distance. Textures are shared between characters; the wrapper supplies independent shader materials and per-character color uniforms. The same small material set serves every palette without duplicating images.

The straw hat uses the two-sided dye-preserving `straw.gdshader` with its own woven straw maps, a high-roughness map, a softer `normal_strength` and an appropriate `detail_scale`. Mesh straw rings remain responsible for the hat silhouette.

Face maps are generated by `source/build_face_textures.py` with Python, NumPy and Pillow. `face_complexion.png` (1024²) packs rose underpaint, soft shade and highlight masks in RGB. The skin shader combines these with the selected skin color. `skin_brush_detail.png` (512²) packs subtle neutral brush variation, height and matte roughness. `iris_fibers.png` (512²) packs radial fibre variation, inner warmth and limbal-ring detail; the iris shader retains the selected eye color. Face/nose UVs share the portrait projection; iris UVs are local discs. These are data maps without baked skin or eye colors.
