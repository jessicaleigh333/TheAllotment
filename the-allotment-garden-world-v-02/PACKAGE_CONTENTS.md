# Ready-to-open Godot project

This smaller package contains the complete playable Godot project, including runtime models, textures, scenes, scripts, documentation and credits. Optional Blender authoring files, raw source meshes and preview screenshots are omitted. The full authoring archive is retained separately.

Extract the ZIP, open Godot Project Manager, choose Import, and select project.godot in The-Allotment-Updated-Gardener. Press F5 to start.
